Уеб приложение за управление на шофьори, превозни средства, товарни пътувания, служители и документи.

## Процес на вход

Входът е в две стъпки при нов акаунт, и в една стъпка при вече активиран.

### Стандартен вход (активиран акаунт)

1. Отвори https://transportfirm-frontend.vercel.app/login
2. Въведи имейл и парола
3. Системата връща JWT токен и пренасочва към началната страница според ролята

### Първи вход (нов акаунт)

При създаване на нов потребител от ADMIN, системата **не задава парола ръчно** — вместо това:

1. Генерира се случайна временна парола (10 символа)
2. Генерира се OTP код (6 цифри, валиден 24 часа)
3. На имейла на потребителя пристига съобщение с временната парола и OTP кода

При вход с временните данни:
1. Системата разпознава, че акаунтът не е активиран (`firstLogin = true`)
2. Връща се специален отговор `403 + { firstLoginRequired: true }`
3. Frontend-ът засича това и пренасочва автоматично към `/first-login`
4. Потребителят въвежда новата си парола + OTP кода за потвърждение
5. Акаунтът се маркира като активиран — при следващ вход процесът е стандартен

### Забравена парола

1. Кликни **"Забравена парола"** на страницата за вход
2. Въведи имейл → получаваш OTP код на имейла
3. Въведи OTP + нова парола → паролата се сменя

## Роли и достъп

Системата има 6 роли. Всяка роля вижда различни секции в навигацията.

---

### ADMIN — Пълен достъп

Единственият начин за създаване на първи ADMIN е чрез bootstrap endpoint (при празна база). След това ADMIN може да създава всички останали роли.

| Достъп до | Действия |
|-----------|----------|
| Шофьори | Преглед, създаване, редактиране, документи |
| Превозни средства | Преглед, създаване, редактиране, документи |
| Служители | Преглед, създаване, редактиране, документи |
| Механици | Преглед на списък и детайли (групи, документи) |
| Диспечери | Преглед на списък и детайли (групи, документи) |
| Товарни пътувания | Преглед, създаване, редактиране |
| Фактури | Генериране и преглед (от товарни пътувания) |
| Счетоводство / Отчети | Пълен достъп + XLSX export |
| Dashboard механик | Четене |
| Dashboard диспечер | Четене |
| Профил | Редактиране на собствен профил |

---

### MANAGER — Почти пълен достъп

Идентичен достъп с ADMIN. Разликата е само на backend ниво — не може да достъпва admin-специфични системни endpoints (`/auth/admin/**`).

---

### DISPATCHER — Диспечер

Работи основно с шофьори и товарни пътувания. Не може да редактира данните на шофьори или превозни средства — само да ги преглежда.

| Достъп до | Действия |
|-----------|----------|
| Шофьори | Преглед и документи (без редактиране) |
| Превозни средства | Преглед и документи (без редактиране) |
| Товарни пътувания | Преглед, създаване, редактиране |
| Dashboard диспечер `/dispatcher` | Групи превозни средства с назначени шофьори |
| Моите документи `/my-documents` | Собствени документи |
| Профил | Редактиране |

---

### MECHANIC — Механик

Вижда само превозните средства от групите, към които е назначен. Може да добавя и редактира записи за техническо обслужване единствено за своите групи.

| Достъп до | Действия |
|-----------|----------|
| Превозни средства | Преглед и документи (без редактиране) |
| Dashboard механик `/mechanic` | Групи превозни средства, история на обслужване |
| Техническо обслужване | Добавяне и редактиране само за assigned групи |
| Моите документи `/my-documents` | Собствени документи |
| Профил | Редактиране |

---

### ACCOUNTANT — Счетоводител

Вижда само финансовата секция. Няма достъп до оперативни данни (шофьори, превозни средства, пътувания).

| Достъп до | Действия |
|-----------|----------|
| Счетоводство / Отчети `/reports` | Фактури, разходи, приходи, XLSX export |
| Моите документи `/my-documents` | Собствени документи |
| Профил | Редактиране |

---

### DRIVER — Шофьор

Най-ограничена роля. Шофьорът влиза в системата само за да види собствените си документи — не вижда никаква оперативна информация.

| Достъп до | Действия |
|-----------|----------|
| Моите документи `/my-documents` | Преглед на собствени документи (read-only) |
| Профил | Редактиране |

## Автоматични известия за документи

Системата проверява ежедневно в 08:00 за изтичащи или изтекли документи (в рамките на 30 дни):

- **Документи на шофьор** → имейл + SMS до шофьора
- **Документи на превозно средство** → имейл + SMS до диспечера и всички ADMIN-и
